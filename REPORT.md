# Grok Voice Agent Accessibility Report

**Title:** Voice agent cuts off dyslexic users mid-thought — silence threshold too short

**Status:** Draft — ready to post
**Audience:** @SpaceXAI, @grok, @elonmusk, @XDevelopers
**Hashtag:** #Accessibility

---

## The Problem

I'm a dyslexic user of the Grok voice agent, and I can't use it.

When I speak, I naturally pause, restart, and rephrase — that's how my brain processes language. The agent treats every pause as the end of my turn and jumps in, cutting me off repeatedly.

This makes the voice feature nearly unusable for me.

## Why This Matters

This isn't a niche issue. Dyslexia affects about one in ten people, so millions of voice users likely hit the same wall. It's a mass accessibility gap, not an edge case.

## Proposed Fix

A simple fix: raise the silence timeout before the agent assumes a turn is finished, or add a user-configurable setting for it.

Even a "wait" command that freezes the agent would help.

## What We Need From the Team

1. Raise the default silence timeout, or make it configurable in settings.
2. Add a "wait" / "hold on" voice command that pauses the agent mid-turn.
3. Consider speech-difference profiles (dyslexia, stutter, pauses) as first-class accessibility needs.

## Offer

Happy to share more detail, record a demo, or test fixes before release.
